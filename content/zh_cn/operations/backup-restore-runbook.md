# 备份和恢复操作手册

本页重点介绍实用的备份和恢复步骤。

在有风险的更改之前使用它：升级、令牌轮换、传输更改、主机迁移或在 Bedrock 和 Java 端拓扑之间切换。

## 备份什么

最低：

- `config/ServerProperties.json`
- 服务包装文件
- 端口和令牌的部署说明

推荐：

- 以前的版本工件
- 记录最后一个已知状态
- 插件配置，例如 `GeyserVoice/config.yml`
- Bedrock 世界包配置文件
- 目前世界上安装的插件包版本
- 服务管理器文件，例如 systemd 单元或面板启动命令
- 运行时覆盖注释是否使用启动标志

## 在改变任何东西之前

当您将要执行以下操作时拍摄快照：

- 升级 VoiceCraft
- 改变传输
- 轮换令牌
- 交换机拓扑
- 更改主机绑定或防火墙规则
- 从插件管理的运行时转移到外部运行时

## 恢复工作流程

1. 停止受影响的服务。
2. 恢复 `ServerProperties.json`。
3. 如果拓扑发生变化，恢复相关插件或插件配置。
4. 如果版本兼容性很重要，请恢复匹配的插件/插件包。
5. 重新启动 VoiceCraft。
6. 重新启动或重新加载 Minecraft 端集成。
7. 验证传输身份验证和绑定流程。

## 恢复不能自动修复的问题

- 防火墙错误
- DNS 或主机可达性问题
- 客户端或插件配置不匹配
- 网络重新设计后的拓扑错误
- 阻止所需传输路径的提供商
- 使用较新的不兼容客户端包的玩家

## 恢复后验证

检查：

1. 服务器干净地启动
2. 已启用所选传输
3. token与集成节点匹配
4. 玩家绑定和音频流再次工作
5. 服务器命令显示预期的客户端/实体
6. 日志不再显示触发恢复的错误

## 备份命名

使用包含以下内容的名称：

- 日期
- VoiceCraft 版本
- 拓扑结构
- 原因

示例：

```text
2026-05-13-voicecraft-1.6.1-bds-before-token-rotation
```

好的名称在事件发生期间很重要，因为它们可以清楚地表明哪个备份属于哪个拓扑。
