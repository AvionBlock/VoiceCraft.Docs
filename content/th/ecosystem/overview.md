# Ecosystem

VoiceCraft ไม่ใช่ mod เดี่ยว แต่เป็นชุด client, server และ integration

## ส่วนประกอบ

- `VoiceCraft`: runtime หลัก client/server/protocol
- `VoiceCraft.Addon`: addon ฝั่ง Bedrock
- `VoiceCraft.Java`: bridge สำหรับ Java/Geyser
- เอกสารและ configurator สำหรับสร้าง world archive

เลือก integration ตาม server ที่ใช้งานจริง
