# Troubleshooting

## Client ต่อ server ไม่ได้

ตรวจ host, port, firewall และ version compatibility

## Addon ต่อไม่ได้

ตรวจ token, transport enabled และ network path

## Bind ไม่ทำงาน

ตรวจว่า addon connected แล้ว, client session active และใช้ binding key ถูกต้อง

## Proximity ผิด

ตรวจ positioning mode, world ID, position updates และ effect settings
