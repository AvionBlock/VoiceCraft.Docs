# ดาวน์โหลด VoiceCraft

ดาวน์โหลด build ที่ตรงกับ deployment ของคุณ ผู้เล่นใช้ `VoiceCraft.Client` ส่วน host ใช้ `VoiceCraft.Server`

สำหรับ Bedrock Dedicated Server มักต้องใช้ `VoiceCraft.Addon.Core.McHttp` หรือ archive จาก [Addon Configurator](/addon-configurator)

สำหรับ local Bedrock world มักใช้ `VoiceCraft.Addon.Core.McWss`
