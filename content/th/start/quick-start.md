# เริ่มอย่างรวดเร็ว

1. เปิดหน้า [Download](/download) แล้วดาวน์โหลด `VoiceCraft.Client` และ `VoiceCraft.Server`
2. รัน server หนึ่งครั้งเพื่อสร้าง `ServerProperties.json`
3. ตั้งค่า `VoiceCraftConfig.Port` และเปิด transport ที่ต้องใช้
4. ติดตั้ง addon หรือ plugin ฝั่ง Minecraft
5. เปิด client, เพิ่ม server, ทดสอบไมโครโฟน
6. ใช้ bind flow เช่น `voicecraft:vcbind <key>` เพื่อผูกผู้เล่นกับ session ของ VoiceCraft
