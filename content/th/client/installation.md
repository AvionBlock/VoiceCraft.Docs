# ติดตั้ง Client

`VoiceCraft.Client` คือแอปที่ผู้เล่นใช้รับไมโครโฟน ส่งเสียง และเล่นเสียงของผู้เล่นใกล้ตัว

## ดาวน์โหลด

ใช้หน้า [Download](/download) แล้วเลือก build ให้ตรง platform: Windows, Linux, macOS, Android arm64 หรือ iOS

## ตั้งค่าพื้นฐาน

1. เปิด client
2. เลือก input/output device
3. ทดสอบไมโครโฟน
4. เพิ่ม server ด้วย host และ port ของ `VoiceCraftConfig.Port`
5. ตรวจสอบว่า client และ server เป็นรุ่นที่เข้ากันได้

บน mobile ต้องอนุญาต microphone permission เมื่อระบบถาม
