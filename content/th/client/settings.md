# Settings

หน้าตั้งค่า client ใช้ปรับเสียง การเชื่อมต่อ และพฤติกรรมของ VoiceCraft

## General

ภาษา, startup behavior และ telemetry preference

## Voice

input device, output device, input gain, noise suppression, AGC และ push-to-talk

## Network

saved servers, `McWssListenIp` และ `McWssHostPort`

ค่า McWss ใช้กับ local Bedrock websocket flow ไม่ใช่ port หลักของ voice UDP server
