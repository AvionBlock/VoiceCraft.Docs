# เอกสาร VoiceCraft

VoiceCraft คือระบบ proximity voice chat สำหรับ Minecraft Bedrock ที่แยกเป็น client, server และ integration ฝั่ง Minecraft

ใช้เอกสารนี้เพื่อเริ่มติดตั้ง client/server, เชื่อมต่อ Bedrock ผ่าน `McHttp` หรือ `McWss`, ปรับแต่งเสียง และดูแนวทางอัปเกรดอย่างปลอดภัย

## เริ่มตรงไหนดี

- ผู้เล่น: ไปที่ [ดาวน์โหลด](/download) และ [ติดตั้ง client](/client/installation)
- ผู้ดูแล server: เริ่มจาก [ติดตั้ง server](/server/installation) และ [ServerProperties.json](/server/server-properties)
- Bedrock Dedicated Server: อ่าน [McHttp for BDS](/minecraft/mchttp-bds)
- local world: อ่าน [McWss Singleplayer](/minecraft/mcwss-singleplayer)
- นักพัฒนา addon: อ่าน [Addon API](/ecosystem/addon-api)
