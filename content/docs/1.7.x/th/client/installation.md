# ติดตั้ง Client สำหรับ 1.7

VoiceCraft `1.7.0` มี native desktop/mobile clients และไม่มี browser/web client ใน core release แล้ว

## Compatibility

- ใช้ client `1.7.x` กับ server `1.7.x`
- Android package version คือ `17`
- iOS มี sample-rate conversion fix และ privacy manifest

## Platforms

- Windows
- Linux
- macOS
- Android arm64
- iOS

หลังอัปเกรด ให้ทดสอบ input/output device และ microphone capture อีกครั้ง โดยเฉพาะ iOS ที่เคยมีเสียงเพี้ยน
