# 備份和復原作業手冊

本頁重點介紹實用的備份和復原步驟。

在有風險的變更之前使用它：升級、令牌輪換、傳輸變更、主機遷移或在 Bedrock 和 Java 端拓撲之間切換。

## 備份什麼

最低：

- `config/ServerProperties.json`
- 服務包裝文件
- 連接埠和令牌的部署說明

推薦：

- 以前的版本工件
- 記錄最後一個已知狀態
- 插件配置，例如 `GeyserVoice/config.yml`
- Bedrock 世界包設定檔
- 目前世界上安裝的插件包版本
- 服務管理器文件，例如 systemd 單元或面板啟動命令
- 運行時覆蓋註釋是否使用啟動標誌

## 在改變任何事物之前

當您將要執行以下操作時拍攝快照：

- 升級 VoiceCraft
- 改變交通工具
- 輪換令牌
- 交換器拓撲
- 更改主機綁定或防火牆規則
- 從插件管理的運行時轉移到外部運行時

## 復原工作流程

1. 停止受影響的服務。
2. 復原 `ServerProperties.json`。
3. 如果拓樸發生變化，恢復相關外掛程式或外掛程式配置。
4. 如果版本相容性很重要，請恢復相符的插件/插件包。
5. 重新啟動 VoiceCraft。
6. 重新啟動或重新載入 Minecraft 端整合。
7. 驗證傳輸身份驗證和綁定流程。

## 恢復不能自動修復的問題

- 防火牆錯誤
- DNS 或主機可達性問題
- 客戶端或外掛程式配置不匹配
- 網路重新設計後的拓樸錯誤
- 阻止所需傳輸路徑的提供者
- 使用較新的不相容客戶端套件的玩家

## 恢復後驗證

檢查：

1. 伺服器乾淨地啟動
2. 已啟用所選傳輸
3. token與整合節點匹配
4. 玩家綁定和音訊串流再次工作
5. 伺服器命令顯示預期的客戶端/實體
6. 日誌不再顯示觸發恢復的錯誤

## 備份命名

使用包含以下內容的名稱：

- 日期
- VoiceCraft 版本
- 拓樸結構
- 原因

範例：

```text
2026-05-13-voicecraft-1.6.1-bds-before-token-rotation
```

好的名稱在事件發生期間很重要，因為它們可以清楚地表明哪個備份屬於哪個拓撲。
