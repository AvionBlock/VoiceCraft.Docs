# 概述

VoiceCraft 是適用於 Minecraft 基岩版和相關橋樑場景的近距離語音平台。

它由幾層組成：

1. `VoiceCraft.Client`
   桌面和行動用戶端應用程式
2. `VoiceCraft.Server`
   用於語音傳輸、狀態同步和傳輸端點的獨立後端
3. 面向 Minecraft 的交通工具
   `McHttp`, `McWss`, and `McTcp`
4. 生態系整合
   `VoiceCraft.Addon` for Bedrock and `GeyserVoice` for Java / proxy stacks

## 它是如何工作的

1. The client connects to `VoiceCraft.Server` over UDP.
2. 伺服器追蹤實體、位置、世界 ID、效果位元遮罩和審核狀態。
3. Minecraft 端傳輸用遊戲狀態更新伺服器：
   - `McHttp` for BDS
   - `McWss` for local Bedrock worlds
   - `McTcp` for `GeyserVoice`
4. 用戶端根據伺服器狀態和選定的本機設定呈現鄰近音訊。

## 支援的客戶端平台

- Windows (`x86`, `x64`, `arm64`)
- Linux (`x64`, `arm32`, `arm64`)
- macOS (`x64`, `arm64`)
- Android (`arm64`)
- iOS (`arm64`, `.ipa`)

## 是什麼讓 VoiceCraft 變得靈活

- 多種 Minecraft 交通工具
- 基岩插件 API 表面
- Java-side bridge via `GeyserVoice`
- 可設定的效果和實體元數據
- 伺服器端與客戶端兩種定位模式
