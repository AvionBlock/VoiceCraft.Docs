This dashboard shows public VoiceCraft telemetry aggregates such as active versions, platform mix, and configuration trends. It helps maintainers understand what is used in the field and which deployment shapes need better support.

Telemetry is controlled by `TelemetryEnabled` in `config/ServerProperties.json`. If you operate a server and do not want it to report anonymous diagnostics, disable telemetry in the server config.
