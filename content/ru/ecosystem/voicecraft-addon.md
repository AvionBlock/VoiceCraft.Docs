# VoiceCraft.Addon (Аддон Bedrock)

Репозиторий: [AvionBlock/VoiceCraft.Addon](https://github.com/AvionBlock/VoiceCraft.Addon)

Этот репозиторий содержит готовые пакеты аддона Bedrock и скриптовый интерфейс McApi для кастомной логики мира.

Используйте его, когда Minecraft Bedrock является источником состояния игрока/сущности. Аддон подключает миры Bedrock к серверу VoiceCraft через `McHttp` или `McWss`, а затем предоставляет процесс привязки, UI, события и помощники пакетов для скриптов мира.

## Пакеты

| Пакет | Цель | Используйте, когда |
|---------|---------|----------|
| `Basic` | готовый к использованию процесс привязки, UI настроек, внутриигровые голосовые индикаторы, общие скриптовые события | вам нужен рабочий пример или поведение Bedrock по умолчанию |
| `Core.McHttp` | Транспортный пакет HTTP | вы используете выделенный сервер Bedrock |
| `Core.McWss` | транспортный пакет WebSocket/командного туннеля | вы запускаете локальный мир Bedrock или тестируете установку |

Большинство реальных установок Bedrock сочетают в себе транспортный пакет с элементами поведения/UI, необходимыми миру.

## Выравнивание версий

VoiceCraft `v1.6.1` требует обновления пакетов аддона вместе с версией клиента/сервера. Этот выпуск включает внутриигровые голосовые значки, улучшения auto-connect, транслируемые события и исправления отключения McHttp/McWss, которые зависят от соответствующих пакетов на стороне аддона.

Не обновляйте сервер/клиент, оставляя старый пакет аддона в мире. Несовпадающие пакеты могут подключиться, но позже сломаться на привязке, событиях или поведении значков.

## Пространство имен

По пакетам:

- `VoiceCraft.Namespace = "voicecraft"`

## Команды

### Basic

- `voicecraft:vcbind <binding_key>`
  разрешение: `Any`
- `voicecraft:vcsettings`
  разрешение: `GameDirectors`

### Core.McHttp

- `voicecraft:vcconnect <hostname> <token>`
  разрешение: `GameDirectors`

### Core.McWss

- `voicecraft:vcconnect <token>`
  разрешение: `Host`
- `voicecraft:data_tunnel [max_string_length] [data]`
  разрешение: `Host`

## Что дает пакет «Basic»

- процесс привязки и отвязки
- интерфейс настроек игрока
- переключение эффектов
- скрипт событий для автоматизации
- внутриигровые индикаторы, используемые поддерживаемыми выпусками

Начните с `Basic`, если вы хотите понять ожидаемый опыт игрока, прежде чем писать собственную логику аддона.

## Детали процесса привязки

Из текущей реализации:

1. новая сетевая сущность получает случайный 5-значный ключ привязки
2. описание сущности обновляется текстом с ключом
3. игрок запускает `voicecraft:vcbind <key>`
4. сущность привязывается к игроку
5. при выходе происходит отвязка и генерируется новый ключ

Скриптовые события:

- `voicecraft:onPlayerBind`
- `voicecraft:onPlayerUnbind`

VoiceCraft `v1.6.1` также транслирует больше событий жизненного цикла и пакетов на стороне аддона, чтобы кастомные миры могли реагировать без прямого опроса транспортного уровня.

Ключ привязки намеренно короткий, потому что он набран в игре. Относитесь к нему как к временному токену ссылки, а не как к долгосрочному секрету.

## Интерфейс эффектов

`voicecraft:vcsettings` в настоящее время предоставляет:

- Visibility
- Proximity
- Directional
- Proximity Echo
- Эхо
- Proximity Muffle
- Muffle

Эффекты отправляются через `McApiSetEffectRequestPacket`.

## Что вы можете настроить

- политика привязки/отвязки
- ограничения на основе ролей или тегов
- правила идентификатора мира
- поведение обновления положения/вращения
- формы для персонала через `@minecraft/server-ui`
- обработчики пакетов на интерфейсе McApi

Настраивайте только после того, как будет работать базовая настройка. Это дает вам проверенную основу для поведения транспорта, привязки и позиционирования.

## Текущие ограничения

- Стабильность `Core.McWss` зависит от ограничений команд и полезной нагрузки
- Ограничения хоста/провайдера могут блокировать сетевой путь, требуемый `Core.McHttp`
- кастомные обработчики пакетов необходимо протестировать на целевой версии Bedrock.

## Рекомендуемая настройка: BDS.

1. включить `McHttpConfig.Enabled = true`
2. убедиться, что BDS может достичь `McHttpConfig.Hostname`
3. скопируйте пакет `Core.McHttp`
4. запустите `voicecraft:vcconnect <hostname> <token>`
5. проверить привязку с помощью `voicecraft:vcbind <key>`

## Рекомендуемая настройка: локальный мир

1. включить `McWss`
2. установить `Core.McWss`
3. запустите `/connect`
4. запустите `voicecraft:vcconnect <token>`
5. сохраняйте соответствие `voicecraft:data_tunnel` конфигурации сервера

## Контрольный список проверки

- установлен правильный транспортный пакет
- пакеты поведения и ресурсов активны
- `vcconnect` использует токен из соответствующего раздела конфигурации сервера.
- игрок может выполнить привязку с помощью `voicecraft:vcbind <key>`
- движение игрока меняет данные о положении в VoiceCraft
- UI эффектов открывается для авторизованных пользователей
