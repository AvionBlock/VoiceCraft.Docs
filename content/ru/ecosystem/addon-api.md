# API аддонов

`VoiceCraft.Addon` предоставляет управляемый скриптами уровень McApi, который намного шире, чем просто `vcbind`.

Эта страница предназначена для разработчиков аддонов и миров.

Используйте API, когда стандартного поведения аддона недостаточно: настраиваемые правила привязки, настраиваемые эффекты, голосовое поведение для конкретного региона, скриптовые поддельные объекты, инструменты для персонала или логика видимости, специфичная для игрового режима.

Начните со стандартного пакета `Basic`. Как только транспорт, привязка и proximity audio заработают, постепенно добавляйте собственную логику пакетов/событий.

## Высокоуровневая поверхность API

API на стороне аддона предоставляет:

- жизненный цикл соединения
- отправка/получение пакета
- создание и уничтожение сущности
- Обновления идентификатора мира, положения, вращения, отключения звука, оглушения и битовой маски
- обновления эффектов
- события приема аудио

API существует для того, чтобы мир мог решить, какой голос должен означать в игровом процессе. VoiceCraft предоставляет модель транспорта и состояния; логика вашего аддона может решить, как сопоставить теги, роли, регионы, измерения или объекты сценария с этой моделью.

## Высокоуровневые события

Из текущего уровня API:

- `OnConnected`
- `OnDisconnected`
- `OnPlayerBind`
- `OnPlayerUnbind`
- `OnPacket`

VoiceCraft `v1.6.1` расширяет этот управляемый событиями путь широковещательными событиями, используемыми пакетами аддона, поэтому мировые сценарии могут реагировать на подключение, привязку и активность пакетов без специального опроса.

События сценария, используемые системой, включают:

- `voicecraft:onConnected`
- `voicecraft:onDisconnected`
- `voicecraft:onPlayerBind`
- `voicecraft:onPlayerUnbind`
- `voicecraft:onPacket`
- `voicecraft:sendPacket`

## Покрытие на уровне пакетов

Текущие события открытых пакетов включают такие категории, как:

- вход/выход/пинг
- принять/отклонить/сбросить ответы
- создание/удаление сущности
- обновление заголовка/описания/имени
- отключить звук/оглушить/отключить звук сервера/оглушить сервер
- битовая маска разговора/слушания/эффекта
- позиция/ротация/идентификатор мира
- фактор пещеры/фактор глушения
- обновления эффектов
- аудио получено

Это делает API аддона полезным не только для стандартных миров, но и для пользовательских режимов игры.

Перехватчики на уровне пакетов эффективны, но ими легко злоупотреблять. Отдавайте предпочтение событиям жизненного цикла высокого уровня для обычной настройки и перехватам пакетов только тогда, когда вам нужен низкоуровневый контроль.

## Общие идеи настройки

- автоматическая привязка по команде, роли или тегу
- UI привязки
- пользовательские настройки эффектов для каждого биома или области
- переназначение идентификатора мира на основе региона
- инструменты модерации персонала через формы пользовательского интерфейса сервера
- заскриптованная голосовая логика NPC или поддельной сущности

## Базовая модель интеграции

Типичная логика аддона:

1. подключиться к транспорту VoiceCraft
2. аутентифицировать
3. создавать или обнаруживать сущности
4. связывать игроков
5. обновить идентификатор мира/позицию/вращение по тику или событию
6. реагировать на обновления на уровне пакетов

Для BDS это обычно означает `Core.McHttp`. Для локальных миров это обычно означает `Core.McWss`.

## Важные замечания по реализации

- Режим `McWss` зависит от пропускной способности командного туннеля
- переключатели эффектов кодируются с помощью битовых масок
- автоматизацию на уровне пакетов следует тщательно протестировать на реальных сборках Bedrock.
- сохраняйте пакеты аддона в соответствии с версией VoiceCraft, если это зависит от транслируемых событий или голосовых значков в игре.
- избегайте отправки ненужных высокочастотных обновлений; Обновления местоположения полезны, но шумные пользовательские циклы пакетов могут привести к нестабильности
- рассматривать токены входа в транспорт как учетные данные сервера, а не как значения, доступные игроку

## Рекомендуемая практика

- начните с `Basic`, если вам нужна рабочая ссылка
- переключитесь на `Core.McHttp` или `Core.McWss` при создании индивидуального опыта
- сначала держите автоматизацию мира тонкой, а затем постепенно расширяйте перехваты пакетов
- проверяйте каждую пользовательскую функцию как минимум с двумя игроками, чтобы проверить proximity audio и поведение привязки

## Отладка пользовательской логики

1. Убедитесь, что стандартный аддон может подключиться и привязаться.
2. Добавьте одно пользовательское событие или перехватчик пакетов.
3. Проверьте, видит ли сервер VoiceCraft обновления объектов.
4. Проверьте движение по мирам/измерениям, если ваша логика меняет идентификаторы мира.
5. Отключите пользовательский код, прежде чем обвинять настройки транспорта или звука.
