# Обзор

VoiceCraft — это голосовая платформа для Minecraft Bedrock Edition и сценариев с мостами.

VoiceCraft позволяет игрокам запускать отдельный голосовой клиент, а автоматизация на стороне Minecraft сообщает голосовому серверу, где находится каждый игрок, в каком мире он находится и какие эффекты или правила видимости нужно применять.

VoiceCraft полезен, когда вам нужен голосовой чат с учетом расстояния, который не привязан к одной конкретной топологии сервера Minecraft. Одно и то же серверное ядро можно комбинировать с аддонами Bedrock, мостами Java/Geyser или прокси-развертываниями.

## Что вы настраиваете

Большинство развертываний состоят из трех движущихся частей:

1. `VoiceCraft.Client`
   настольное и мобильное приложение, установленное каждым игроком
2. `VoiceCraft.Server`
   автономный бэкэнд для голосового трафика, синхронизации состояния, модерации и транспортных эндпоинтов
3. Транспорт, ориентированный на Minecraft
   `McHttp`, `McWss` и `McTcp`

Интеграция экосистемы соединяет Minecraft с этими транспортами:

- `VoiceCraft.Addon` для миров Bedrock и BDS
- `GeyserVoice` для стеков Java/Geyser/Proxy

## Как это работает

1. Клиент подключается к `VoiceCraft.Server` через UDP.
2. Сервер отслеживает голосовые сеансы, сущности, позиции, идентификаторы миров, битовые маски эффектов и состояние модерации.
3. Интеграция со стороны Minecraft обновляет сервер с состоянием игрового процесса:
   - `McHttp` для BDS
   - `McWss` для локальных миров Bedrock
   - `McTcp` для `GeyserVoice`
4. Клиент воспроизводит звук с учетом расстояния в соответствии с состоянием сервера и выбранными локальными настройками.

Голосовое соединение и транспортное соединение Minecraft разделены. Если подключена только одна сторона, установка может выглядеть частично работоспособной, но поведение звука с учетом расстояния все равно будет неполным.

## Поддерживаемые клиентские платформы

- Windows (`x86`, `x64`, `arm64`)
- Linux (`x64`, `arm32`, `arm64`)
- macOS (`x64`, `arm64`)
- Android (`arm64`)
- iOS (`arm64`, `.ipa`)

## Что делает VoiceCraft гибким

- несколько транспортов Minecraft
- API-интерфейс аддона Bedrock
- мост на стороне Java через `GeyserVoice`
- кастомные эффекты и метаданные сущностей
- режимы позиционирования как на стороне сервера, так и на стороне клиента

Эта гибкость также означает, что первое решение имеет значение: сначала выберите топологию, а затем следуйте инструкциям для этого транспорта.

## Распространенные варианты топологии

| Если у вас... | Начните с... | Почему |
|---------------|---------------|-----|
| Выделенный сервер Bedrock | [McHttp for BDS](/minecraft/mchttp-bds) | BDS может вызывать стабильный HTTP-эндпоинт |
| Локальный мир Bedrock | [McWss for Singleplayer Worlds](/minecraft/mcwss-singleplayer) | Работает через локальный WebSocket/командный туннель. |
| Java-сервер с Geyser/Floodgate | [GeyserVoice](/ecosystem/geyservoice) | Плагин на стороне Java подключается к VoiceCraft через `McTcp` |
| Сервер Direct Paper | [GeyserVoice Direct Paper](/ecosystem/geyservoice-direct-paper) | Плагин может использовать внешний сервер или управлять средой выполнения. |
