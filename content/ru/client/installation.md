# Установка клиента

`VoiceCraft.Client` — приложение для игроков. Каждому игроку, который хочет говорить или слышать голос с учетом расстояния, необходимо, чтобы он был запущен на его собственном устройстве.

Установите клиент после того, как `VoiceCraft.Server` станет доступен. Во время первого запуска вы добавите запись сервера, указывающую на UDP-эндпоинт VoiceCraft, обычно `host:9050`.

## Прежде чем начать

Вам нужно:

- адрес сервера, который игроки должны использовать
- UDP-порт сервера из `VoiceCraftConfig.Port`
- микрофон и устройство воспроизведения, доступные операционной системе
- сопоставление `Positioning Type` между клиентом и сервером

Для локального тестирования эндпоинтом обычно является:

```text
127.0.0.1:9050
```

Для удаленных серверов используйте общедоступный или локальный адрес компьютера, на котором работает `VoiceCraft.Server`.

## Windows

1. Загрузите `VoiceCraft.Client.Windows.<Architecture>.v1.7.0.zip`.
2. Распакуйте архив.
3. Запустите `VoiceCraft.Client.Windows.exe`.
4. Если появится Windows SmartScreen, прежде чем продолжить, убедитесь, что файл взят с официальной страницы выпуска.

## Linux

1. Загрузите `VoiceCraft.Client.Linux.<Architecture>.v1.7.0.zip`.
2. Распакуйте архив.
3. Предоставьте разрешения и запустите:

```bash
chmod +x ./VoiceCraft.Client.Linux
./VoiceCraft.Client.Linux
```

Если приложение не видит аудиоустройства, проверьте разрешения PulseAudio/PipeWire и проверьте, работает ли приложение в изолированной программной среде с ограниченным доступом.

## macOS

Выберите ZIP-пакет под свое устройство:

- `VoiceCraft.Client.MacOS.arm64.v1.7.0.zip` для Apple Silicon
- `VoiceCraft.Client.MacOS.x64.v1.7.0.zip` для Intel

1. Распакуйте архив.
2. Запустите `VoiceCraft.app`.

Если macOS блокирует запуск:

```bash
xattr -dr com.apple.quarantine /Applications/VoiceCraft.app
```

Удаляйте карантин только для тех сборок, которые вы намеренно загрузили и которым доверяете.

## Андроид

1. Загрузите `VoiceCraft.Client.Android.<Architecture>.v1.7.0.zip`.
2. Распакуйте архив.
3. Откройте `.apk` из архива и установите.
4. Разрешите разрешение микрофона, когда Android спросит.

## iOS (AltStore/неопубликованная загрузка)

1. Загрузите `VoiceCraft.Client.iOS.arm64.v1.7.0.zip`.
2. Установите IPA через AltStore или другой инструмент для боковой загрузки.
3. При необходимости разрешите профиль в настройках iOS.
4. Разрешить доступ к микрофону при первом запуске.

## Примечание о среде выполнения .NET

Для более старых выпусков (до `v1.4.0`) может потребоваться установленная среда выполнения .NET 9.
Для текущих автономных сборок это обычно не требуется.

## Контрольный список первого запуска

1. Откройте клиент.
2. Выберите устройства ввода и вывода.
3. Используйте тест микрофона, чтобы подтвердить уровень входного сигнала.
4. Добавьте запись сервера:
   - хост: адрес сервера VoiceCraft.
   - порт: `VoiceCraftConfig.Port`
5. Убедитесь, что `Positioning Type` соответствует серверу.
6. Подключитесь перед запуском процесса привязки Minecraft.

Успешное подключение клиента доказывает только доступность голосового эндпоинта. Звук с учетом расстояния в Minecraft по-прежнему зависит от аддона или плагина, который подключается к соответствующему транспорту.

## Распространенные проблемы при первом запуске

- Нет микрофонного входа:
  проверьте разрешение микрофона ОС и выбранное устройство ввода.
- Клиент подключается, но нет звука с учетом расстояния:
  проверьте транспорт Minecraft, процесс привязки и `Positioning Type`.
- Удаленный сервер не подключается:
  убедитесь, что порт UDP между игроком и `VoiceCraft.Server` открыт.
- Игрок слышит всех на неправильном расстоянии:
  проверьте обновления позиции сущности и идентификаторы миров.
