# McWss для одиночных миров

`McWss` — это транспорт веб-сокетов/командного туннеля, который в основном используется для локальных миров и облегченных установок Bedrock.

Используйте это руководство, если у вас не используется полноценный выделенный сервер Bedrock и вам нужен локальный мир Bedrock для связи с VoiceCraft через поток веб-сокета `/connect`.

Форма цели:

```text
VoiceCraft.Client -> VoiceCraft UDP endpoint
Local Bedrock world + VoiceCraft.Addon.Core.McWss -> McWss websocket endpoint
```

## Когда его использовать

Используйте `McWss`, когда:

- вы играете в местном мире Bedrock
- вам нужна быстрая настройка одиночной игры
- вы тестируете логику дополнения без выделенного хоста BDS

Если вы используете настоящий выделенный сервер Bedrock, используйте вместо него [McHttp for BDS](/minecraft/mchttp-bds).

## Важные ограничения

- обычно менее стабилен, чем `McHttp`
- Пропускная способность команд и размер полезной нагрузки имеют большое значение
- не рекомендация по умолчанию для крупных общедоступных производственных сред
- зависит от веб-сокета Bedrock и поведения команд, доступных в вашей среде

## Требования

1. `VoiceCraft.Server` с `McWssConfig.Enabled = true`
2. `VoiceCraft.Addon.Core.McWss.zip`
3. Сборка Bedrock, поддерживающая необходимые функции веб-сокета/скрипта.
4. Клиент VoiceCraft установлен и настроен.
5. соответствие `McWssConfig.LoginToken` для аутентификации надстройки

Полезные ссылки:

- [Download Page](/download) для исходного пакета выпуска `Core.McWss`
- [Addon Configurator](/addon-configurator) для готового к распаковке мирового архива

## Конфигурация сервера VoiceCraft

Типичная установка:

```json
{
  "McWssConfig": {
    "Enabled": true,
    "LoginToken": "replace-with-token",
    "Hostname": "ws://127.0.0.1:9051/",
    "MaxClients": 1,
    "MaxTimeoutMs": 10000,
    "DataTunnelCommand": "voicecraft:data_tunnel",
    "CommandsPerTick": 3,
    "MaxByteLengthPerCommand": 300,
    "DisabledPacketTypes": []
  }
}
```

Сохраняйте соответствие `DataTunnelCommand` пакету дополнений. Если вы измените его в конфигурации сервера, аддон должен будет использовать то же имя команды.

Для локального однопользовательского тестирования оставьте хост веб-сокета на `127.0.0.1`. Используйте более широкую привязку только в том случае, если мир Bedrock подключается с другой машины.

## Установка

### Вариант 1: импортировать как `.mcaddon`

1. Переименуйте архив в `VoiceCraft.Addon.Core.McWss.mcaddon`.
2. Откройте его, чтобы Minecraft импортировал аддон.
3. Включите пакет поведения и пакет ресурсов в мире.

### Вариант 2: копирование вручную

1. Распакуйте архив.
2. Скопируйте `RP` и `BP` в каталоги Bedrock.
3. Включите оба пакета в целевом мире.

Пакет ресурсов предоставляет видимые ресурсы. Пакет поведения содержит команды, сценарии и логику моста.

## Порядок подключения

### Шаг 1: подключите мировой веб-сокет

```text
/connect <VOICECRAFT_HOST>:<MCWSS_PORT>
```

Пример:

```text
/connect 127.0.0.1:9051
```

Это соединяет мир Bedrock с веб-сокетным транспортом VoiceCraft. Он еще не аутентифицирует аддон.

### Шаг 2: аутентифицируйте аддон

```text
/voicecraft:vcconnect <LOGIN_TOKEN>
```

Используйте `McWssConfig.LoginToken`.

После аутентификации дополнение может отправлять объекты и привязывать данные через командный туннель.

## Туннель данных

Аддон использует:

- `voicecraft:data_tunnel`

Это должно оставаться в соответствии с `McWssConfig.DataTunnelCommand`.

Если вы переименуете одну сторону, а не другую, мост сломается.

В настоящее время команда несет в себе:

- необязательный аргумент максимальной длины строки
- Аргумент упакованных данных полезной нагрузки

Туннель чувствителен к пропускной способности команд. Большие пакеты обновлений сущностей или эффектов могут привести к задержкам или нестабильной доставке, особенно на компьютерах низкого уровня.

## Тюнинг

Если вы видите задержку или нестабильность пакетов:

- нижний `CommandsPerTick`
- просмотреть `MaxByteLengthPerCommand`
- избегайте больших пакетных обновлений
- протестируйте с меньшим количеством активных объектов
- сохраняйте локальную настройку во время настройки
- переключитесь на `McHttp`, если мир станет долгоживущим общим сервером

## Когда переходить на другой транспорт

Перейдите к `McHttp`, если:

- у вас есть настоящий выделенный сервер Bedrock
- вы хотите более чистое производственное развертывание
- нестабильность командного туннеля становится проблемой

В этом случае продолжайте с [McHttp for BDS](/minecraft/mchttp-bds).

## Контрольный список проверки

- `McWssConfig.Enabled = true`
- мир может запустить `/connect <host>:<port>`
- `/voicecraft:vcconnect <LOGIN_TOKEN>` успешно выполнено
- Клиент VoiceCraft подключается к конечной точке UDP
- `PositioningType` соответствует между клиентом и сервером
- поток привязки работает в игре
- перемещение игрока меняет поведение близости

## Общие проблемы

- `/connect` не работает:
  проверьте хост/порт и разрешает ли Bedrock соединения через веб-сокеты в вашей среде.
- `vcconnect` не работает:
  подтвердите, что вы использовали `McWssConfig.LoginToken`.
- ошибки туннеля данных:
  подтвердите, что `DataTunnelCommand` соответствует пакету дополнения.
- звук подключается, но близость неправильная:
  проверьте поток привязки, режим позиционирования и поступают ли обновления местоположения.
